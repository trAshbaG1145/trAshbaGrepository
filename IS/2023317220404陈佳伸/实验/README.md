# 3DES-CBC 文件加解密工具使用教程

本工具是一个基于 Python 实现的轻量级安全软件，专门用于对任意格式的文件进行加密和解密。它采用了 **3DES (Triple DES)** 算法、**CBC (密码分组链接)** 工作模式以及 **PKCS7** 填充标准 。

---

##  环境准备

1. **Python 版本**：确保你的计算机上安装了 **Python 3.6** 或更高版本。
2. **无需第三方库**：本工具完全使用 Python 标准库（如 `hashlib`, `os`, `argparse`）开发，无需安装额外的依赖。
3. **准备脚本**：确保 `file_encryptor.py` 文件已保存在你的本地目录。

---

##  快速入门

### 1. 加密文件 (Encrypt)

如果你想加密一个名为 `my_secret.txt` 的文件，并生成加密文件 `my_secret.enc`：

```bash
python file_encryptor.py encrypt -i my_secret.txt -o my_secret.enc

```

* **输入密码**：程序会提示 `请输入加密密码:`。
* 
**安全特性**：为了安全，你输入密码时屏幕**不会显示**任何字符（盲打） 。


* **确认密码**：再次输入相同的密码以确保无误。

### 2. 解密文件 (Decrypt)

如果你想将加密后的 `my_secret.enc` 还原为 `original.txt`：

```bash
python file_encryptor.py decrypt -i my_secret.enc -o original.txt

```

* **输入密码**：输入你加密时设置的原始密码。
* 
**验证机制**：如果密码错误，程序会提示“填充数据无效”，因为错误的密钥无法正确移除 PKCS7 填充 。

##  参数说明

| 参数 | 缩写 | 描述 | 是否必选 |
| --- | --- | --- | --- |
| `command` | - | `encrypt` (加密) 或 `decrypt` (解密) | **是** |
| `--input` | `-i` | 待处理的源文件路径 | **是** |
| `--output` | `-o` | 处理后保存的目标文件路径 | **是** |

---

##  技术核心

为了保证安全性，本软件在后台自动处理了以下复杂操作：

* 
**密钥派生**：通过 SHA-256 哈希算法将你的文本密码转化为 24 字节（192 位）的 3DES 强密钥 。


* 
**随机 IV (初始向量)**：每次加密都会生成随机的 8 字节 IV，并存储在加密文件的头部 。即使对同一文件使用相同密码加密两次，生成的密文也会完全不同。


* 
**PKCS7 填充**：根据分组密码要求，自动将明文填充至 8 字节的倍数。填充值为缺少的字节数 。例如，若缺少 7 个字节，则填充 `07 07 07 07 07 07 07` 。


* 
**字节流处理**：程序以二进制流形式读写文件，支持图片、视频、文档等任意文件格式 。



---

## ⚠️ 注意事项

* **密码找回**：请务必牢记你的密码！由于采用强加密算法，如果密码丢失，将没有任何办法可以恢复加密后的数据。
* 
**文件安全**：加密后的 `.enc` 文件可以通过 UltraEdit 等编辑器查看十六进制内容，你会发现除了开头的 8 字节 IV 外，其余内容均已不可读 。
