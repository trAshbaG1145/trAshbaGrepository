# 03_项目定位

先来看项目定位。这是一个面向就业场景的关系网络分析与职业推荐系统。核心思路是将招聘岗位信息转化为知识图谱：从数据中抽取职位、公司、技能、学历、经验、城市六类实体和五种关系，存储在Neo4j图数据库中。在此基础上提供知识图谱浏览、职业推荐、AI问答和简历分析等功能。数据方面我们使用了八百零三条岗位样本数据。

# 05_系统架构

来看系统整体架构。我们采用了三服务协作架构：最上层是Vue 3前端展示层，负责页面路由、图谱可视化和用户交互。中间是Flask AI分析引擎，负责知识图谱查询、推荐算法、AI问答和时间线分析，并调用DeepSeek-V3大模型。下面是Spring Boot业务服务层，处理用户管理、职位卡片和JWT鉴权。最底层是数据存储层，包括MySQL业务数据库、Neo4j图数据库和Redis缓存。

---

# 06_技术栈

技术栈方面，前端使用Vue 3加Element Plus加ECharts 5，构建单页应用和图谱可视化。后端使用Spring Boot 3.4加MyBatis-Plus，负责业务接口和JWT认证。AI服务使用Flask加Neo4j，通过SiliconFlow平台调用DeepSeek-V3大模型。整体是一个从前端到业务后端到AI引擎的完整链路。

# 12_时间线

职业时间线分析是AI模块的应用之一。输入职业名称后，AI模型自动生成四个发展阶段：初级阶段零到两年，入门技能掌握；发展阶段二到五年，专业技术深化；成熟阶段五到十年，团队管理和技术决策；专家阶段十年以上，行业影响力建设。每个阶段包含背景、关键事件和技能要求，通过时间线组件直观展示职业成长路径。

# 16_推荐算法

推荐算法流程包含五个步骤。第一步用户输入自我描述，包含技能、学历、经验等自然语言。第二步NLP关键词提取，识别和提取技能、学历、经验实体。第三步Neo4j图数据库查询，找到满足条件的岗位。第四步多维匹配评分计算，我们设计了四个维度的权重：技能命中占四成，学历匹配占两成半，经验匹配占两成半，薪资匹配占一成。第五步Top-K排序输出，返回推荐结果并生成图谱可视化解释。这个算法的核心优势是可解释性强——每个推荐都有关系依据，不是黑盒模型。

---

# 17_大模型

大语言模型方面，我们通过OpenAI兼容接口接入SiliconFlow平台的DeepSeek-V3模型。三个功能模块使用不同的Prompt模板：AI职业问答使用SSE流式响应和Markdown渲染，职业时间线根据职业名自动生成四阶段分析，简历智能匹配支持多格式文本提取和AI职业匹配。AI返回的Markdown由前端渲染成时间线、问答卡片和分析报告，实现AI与传统图谱查询的互补。
