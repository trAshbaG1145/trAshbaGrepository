# 复习笔记使用说明

本目录包含了完整的课程复习笔记。

## 📁 文件结构

```
notes/
├── README.md              (本文档)
├── *_笔记.md              (5个单讲笔记)
├── 完整复习笔记.md         (所有笔记合并)
└── 笔记索引.md            (快速导航)
```

## 📝 文件说明

- **单讲笔记**: 独立的章节笔记,适合逐章学习
- **完整笔记**: 包含所有章节的完整版,适合通读和打印
- **索引**: 提供快速导航和统计信息

## ⭐ 标记说明

- ⭐⭐⭐ 核心知识点(必须掌握)
- ⭐⭐ 重要知识点(需要理解)
- ⭐ 补充内容(了解即可)
- 🎯 考试重点
- 💻 实践应用
- 💡 重点总结
- 🔗 知识关联
