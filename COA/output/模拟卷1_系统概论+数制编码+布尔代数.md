### 三、简答题

1. **三大核心思想：**
   - 存储程序、程序控制：程序预存于主存，CPU按顺序取指执行
   - 二进制编码：一切信息（指令、数据）均用二进制表示
   - 五大功能部件：运算器、控制器、主存储器、输入设备、输出设备
   
   结构关系：CPU=运算器+控制器；主机=CPU+主存；外设=输入+输出；各部件通过总线(BUS)连接。

2. **四种机器码的应用场景：**
   - 原码：用于浮点数的尾数表示
   - 反码：已基本淘汰不用
   - 补码：整数运算标准（50年代起）
   - 移码：用于浮点数的阶码
   
   补码的优势：① 零的表示唯一；② 符号位可直接参与运算；③ 减法可转换为加法（通过求补），使加减电路统一。

3. **规格化**是指使浮点数尾数的绝对值最高有效位为1的表示方式。目的：
   - 使浮点数表示唯一化
   - 充分利用尾数的有效位数，提高精度
   
   例：0.00101×2⁵ 规格化后 → 0.101×2³（左移2位，阶码减2）

4. **卡诺图化简步骤：**
   ① 按变量数画卡诺图（n变量→2ⁿ格）
   ② 将函数所含最小项对应的格填1
   ③ 画卡诺圈：圈住相邻的1格，圈的大小必须是2的幂(1,2,4,8...)，圈越大越好
   ④ 每个1格至少被圈一次，圈内至少有一格未被其他圈覆盖
   ⑤ 每个圈写出一个与项（消去变化变量，保留不变变量）
   ⑥ 所有与项相或得最简式

### 四、计算题

1. **(1) 平均CPI：**
   CPI = 1×0.50 + 2×0.25 + 4×0.15 + 3×0.10
       = 0.50 + 0.50 + 0.60 + 0.30 = **1.90**

   **(2) MIPS：**
   MIPS = f / (CPI × 10⁶) = 1.5×10⁹ / (1.90 × 10⁶) = 1500/1.90 ≈ **789.5**

   **(3) CPU执行时间Te：**
   Te = CPI × 指令数 / f = 1.90 × 3×10⁵ / (1.5×10⁹)
      = 5.7×10⁵ / 1.5×10⁹ = **3.8×10⁻⁴ 秒**

2. **(1) (C0A80000)₁₆ 展开：**
   C=1100, 0=0000, A=1010, 8=1000, 0=0000, 0=0000, 0=0000, 0=0000
   32位二进制：**1100 0000 1010 1000 0000 0000 0000 0000**

   **(2) 解析：**
   - S = 1（负数）
   - E = 10000001₂ = 129
   - e = E - 127 = 129 - 127 = **2**
   - M = 0101000...0₂ → 1.M = 1.0101₂

   **(3) 十进制值：**
   x = (-1)¹ × 1.0101₂ × 2² = -1.0101₂ × 4 = -101.01₂
   101.01₂ = 4 + 1 + 0.25 = 5.25
   **x = -5.25**
