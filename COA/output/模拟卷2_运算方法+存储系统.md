### 三、简答题

1. **浮点加减五步：**
   ① **对阶**：小阶向大阶对齐，阶差决定尾数右移位数。确保小数点对齐。
   ② **尾数求和**：对齐后的尾数进行补码加/减运算。
   ③ **规格化**：左规（尾数左移，阶码减小）或右规（尾数右移，阶码增大），使尾数绝对值最高位为1。
   ④ **舍入**：对多余的尾数位进行舍入处理（0舍1入或末位恒置1）。
   ⑤ **溢出判断**：检查阶码是否溢出（上溢/下溢）。

2. **SRAM vs DRAM：**
   | 特性 | SRAM | DRAM |
   |------|------|------|
   | 存储原理 | 触发器(6个MOS管) | 电容+1个MOS管 |
   | 速度 | 快（纳秒级） | 较慢 |
   | 集成度 | 低（单bit面积大） | 高（单bit面积小） |
   | 刷新 | 不需要 | 需要周期性刷新 |
   | 功耗 | 工作时功耗大 | 工作时功耗小 |
   | 应用 | Cache | 主存 |

3. **三种映射方式对比：**
   - **全相联**：任意主存块可映射到任意Cache行。冲突概率最低，利用率最高，但比较器多(每个行都需要比较)，仅适用于小容量Cache。
   - **直接相联**：每块固定映射到特定行。硬件最简单（仅1个比较器），但冲突概率最高，利用率低。
   - **组相联**：折中方案。Cache分为若干组，组间直接映射，组内全相联。k路组相联需要k个比较器。目前主流方案。

4. **TLB工作原理：**
   - TLB是页表(慢表)的高速缓存，位于CPU内部，使用相联存储器实现
   - 当CPU发出虚地址时，TLB用虚拟页号(VPN)并行查找
   - 命中：直接获得物理页号(PPN)，与页内偏移拼接得到物理地址
   - 缺失：访问主存中的页表，获取PTE后加载到TLB中
   - TLB有效减少了地址转换对主存的访问次数

### 四、计算题

1. **Booth乘法：**
   [X]补 = 1.0011（X=-0.1101），[-X]补 = 0.1101
   [Y]补 = 0.1011

   | 步骤 | 部分积 | 乘数(含附加位) | YₙYₙ₊₁ | 操作 |
   |------|--------|---------------|---------|------|
   | 初始 | 00.0000 | 0.1011 **0** | — | — |
   | 1 | +[-X]补 | | 10 | 加[-X]补→00.1101 |
   | | 右移1位→**00.0110** | 1.0101 1 | | |
   | 2 | — | | 11 | +0 |
   | | 右移1位→**00.0011** | 0.1010 1 | | |
   | 3 | +[X]补 | | 01 | 加[X]补→01.0110 |
   | | 右移1位→**00.1011** | 0.0101 0 | | |
   | 4 | — | | 10 | 加[-X]补→01.1000 |
   | | 右移1位→**00.1100** | 0.0010 1 | | |
   | 5(最后) | +[X]补 | | 01 | 加[X]补→01.1111 |
   | | 不移位 | | | |

   [X×Y]补 = **1.01110001**

2. **Cache性能计算：**
   (1) **命中率 H = 4850/(4850+150) = 4850/5000 = 0.97 = 97%**
   (2) **平均访问时间 ta = H×tc + (1-H)×tm = 0.97×20 + 0.03×200 = 19.4 + 6.0 = 25.4ns**
   (3) **访问效率 e = tc/ta × 100% = 20/25.4 × 100% ≈ 78.7%**

### 五、设计题

**解决方案：**
- 目标：64K×8位；芯片规格：64K×4位
- 扩展方式：**位扩展**（字长扩展）
- 芯片数：d = (64K/64K) × (8/4) = 2片

**连接说明：**
- 地址总线 A₁₅~A₀（16位）：两片芯片共享全部地址线 → 64K寻址
- 数据总线：
  - 芯片1的数据线接 D₃~D₀（低4位）
  - 芯片2的数据线接 D₇~D₄（高4位）
- 控制信号：
  - MREQ# → 两片芯片的 CS#（片选）并联
  - R/W# → 两片芯片的 WE#（写使能）并联

```
                    CPU
        ┌───────────┼───────────────┐
        │           │               │
    A[15:0]      D[7:0]        R/W#,MREQ#
        │        ┌──┴──┐        ┌───┴───┐
   ┌────┼────────┤     │        │        │
   │    │    D[3:0]│ D[7:4]│   │        │
┌──┴────┴──┐  ┌───┴───────┴──┐   │        │
│  SRAM #1  │  │  SRAM #2    │   │        │
│  64K×4   │  │  64K×4     │   │        │
│ D3..D0   │  │ D7..D4     │   │        │
│ A15..A0  │  │ A15..A0    │   │        │
│ CS# WE#  │  │ CS# WE#    │   │        │
└──┬───┬───┘  └──┬────┬─────┘   │        │
   │   └─────────┼────┼─────────┘        │
   └─────────────┘    └──────────────────┘
   地址共用           控制共用
```

两片芯片构成位扩展：容量不变(64K)，字长从4位扩展到8位。
