### 三、简答题

1. **硬布线 vs 微程序：**

   | 特性 | 硬布线控制器 | 微程序控制器 |
   |------|------------|------------|
   | 设计方法 | 组合逻辑/FSM，需列状态表、写布尔表达式 | 软件化设计，编写微程序 |
   | 速度 | 快（直接产生控制信号） | 慢（频繁读控存） |
   | 灵活性 | 差（修改需重新设计电路） | 好（修改微程序即可） |
   | 结构 | 不规则，设计调试困难 | 规整，层次清晰 |
   | 成本 | 高 | 低 |
   | 适用场景 | RISC (MIPS, ARM) | CISC (x86) |

2. **MIPS单周期CPU数据通路：**
   核心组件：PC→指令存储器IM→寄存器堆→ALU→数据存储器DM。
   
   lw $t0, 100($t1) 执行过程：
   ① PC→IM，取指令
   ② 指令译码：op=lw, rs=$t1, rt=$t0, imm=100
   ③ 读寄存器堆：读出 $t1 的值
   ④ ALU计算地址：$t1 + SignExt(100) → ALU结果
   ⑤ 用ALU结果作为地址读DM
   ⑥ DM读出数据→寄存器堆，写入$t0
   ⑦ PC+4→PC

3. **水平型 vs 垂直型微指令：**
   - **水平型**：字长长，一位对应一个控制信号，可同时发出多个微操作，并行性高，速度快，但控存容量大。
   - **垂直型**：用微操作码编码表示操作，类似机器指令格式，字长短，控存容量小，但需要译码才能产生控制信号，速度慢，并行性低。
   - 现代高性能处理器多采用水平型（或混合型）。

4. **RISC五大设计原则：**
   ① 指令条数少、指令格式固定（Load/Store架构）
   ② 寻址方式少且简单
   ③ 大多数指令单周期执行
   ④ 硬布线控制（非微程序）
   ⑤ 大量通用寄存器，注重编译优化
   
   现代处理器倾向RISC原因：简化设计使其易于流水线和超标量实现；编译器技术的进步可弥补指令简单带来的"效率损失"；高主频和并行执行带来的收益远超复杂指令带来的"单条指令效率"。

### 四、计算/分析题

1. **指令格式设计：**
   - 53种操作 → 操作码至少 ⌈log₂53⌉ = **6位**
   - 16个通用寄存器 → 每个寄存器地址需要 4位
   - **二地址指令格式**：[OP:6位] [RS:4位] [RD:4位]，共14位，剩余2位可用于扩展
   - 若6位OP全用于二地址指令，最多 2⁶-保留 = 约60条二地址指令
   
   **扩展操作码方案：**
   - 二地址指令：OP为 000000~110011（52条），格式 [OP:6][RS:4][RD:4]
   - 一地址指令：OP前6位=110100~111011（12条），格式 [OP:10][R:4] → 12×2⁴=192条
   - 零地址指令：OP前6位=111100~111111（4条），格式 [OP:16] → 4×2⁸=1024条

2. **MIPS指令分析：**
   (1) 指令格式：
   - addi → **I型**
   - add → **R型**
   - slt → **R型**
   - bne → **I型**

   (2) add $t2, $t0, $t1 的机器码：
   - R型格式：[op:6][rs:5][rt:5][rd:5][shamt:5][funct:6]
   - op(add)=000000, rs($t0)=01000, rt($t1)=01001, rd($t2)=01010, shamt=00000, funct(add)=100000
   - 即：**000000 01000 01001 01010 00000 100000**
   - 十六进制：**0x01095020**

   (3) 程序执行分析：
   循环共执行5次（t0从5到9，当t0=10时不再小于t1=10，bne不跳转）
   第1次循环：t2=5+10=15, t0→6
   第2次循环：t2=6+10=16, t0→7
   第3次循环：t2=7+10=17, t0→8
   第4次循环：t2=8+10=18, t0→9
   第5次循环：t2=9+10=19, t0→10
   循环结束后 $t2 = **19**

### 五、设计题

**(1) 各指令执行周期RTL：**

**LOAD R0, addr（直接寻址）：**
```
MEX·T1: IR(addr)→AR      IRout, ARin
MEX·T2: Read              Read
MEX·T3: Mem[AR]→DR       DREin, Read
MEX·T4: DR→R0            DRout, R0in
```

**MOVE R1, imm：**
```
MEX·T1: IR(imm)→R1       IRout, R1in
```

**ADD R0, R1：**
```
MEX·T1: R0→X             R0out, Xin
MEX·T2: (X)+(R1)→Z       R1out, ADD
MEX·T3: Z→R0             Zout, R0in
```

**STORE R0, (R2)（寄存器间接寻址）：**
```
MEX·T1: R2→AR            R2out, ARin
MEX·T2: R0→DR            R0out, DRin
MEX·T3: DR→Mem[AR]       DREout, Write
```

**JMP addr：**
```
MEX·T1: IR(addr)→PC      IRout, PCin
```

**(2) Read控制信号的布尔表达式：**

Read信号在两种情况下需要为1：
- 取指周期中读取指令：MIF·(T2+T3)
- LOAD指令执行周期中读取数据：LOAD·MEX·(T2+T3)
- STORE指令中不需要Read（只需要Write）

**Read = MIF·(T2+T3) + LOAD·MEX·(T2+T3)**
      = **(MIF + LOAD·MEX) · (T2+T3)**
