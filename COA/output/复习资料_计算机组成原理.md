## M01 系统概论

### 1.1 冯诺依曼结构（★必考）

**三大核心思想：**
1. **存储程序，程序控制** — 程序和数据预先存入主存，按地址顺序执行
2. **二进制编码** — 一切信息用二进制表示
3. **五大功能部件** — 运算器、控制器、主存储器、输入设备、输出设备

**五大部件关系：**
```
CPU = 运算器 + 控制器
主机 = CPU + 主存储器
外设 = 输入设备 + 输出设备
各部件通过总线 (BUS) 连接
```

### 1.2 计算机性能指标（★★核心计算）

#### 非时间指标
| 指标 | 定义 |
|------|------|
| 机器字长 | CPU一次能处理的二进制位数（由运算器、寄存器位数决定） |
| 总线宽度 | 数据总线一次并行传送的最大信息位数 |
| 主存容量 | 主存包含的存储单元总数 |
| 存储带宽 | 单位时间内与主存交换的二进制信息量 (Byte/s) |

#### 时间指标（必背公式）
| 指标 | 符号 | 公式 | 单位 |
|------|------|------|------|
| 主频 | f | — | MHz, GHz |
| 时钟周期 | T | **T = 1/f** | 秒 |
| 外频与倍频 | — | **主频 = 外频 × 倍频** | — |
| CPI | CPI | **CPI = Σ(CPIᵢ × 比例ᵢ)** | 周期/指令 |
| MIPS | — | **MIPS = f / (CPI × 10⁶)** | 百万条/秒 |
| CPU执行时间 | Te | **Te = CPI × 指令条数 × T = CPI × 指令条数 / f** | 秒 |
| MFLOPS | — | **MFLOPS = 浮点运算次数 / (执行时间 × 10⁶)** | 百万次/秒 |

#### 经典例题
已知：f=1GHz，指令数=2×10⁵，四类指令的CPI和比例分别为 (1, 60%), (2, 18%), (4, 12%), (8, 10%)
- **CPI = 1×0.6 + 2×0.18 + 4×0.12 + 8×0.1 = 2.24**
- **MIPS = 10⁹ / (2.24 × 10⁶) ≈ 446.4**
- **Te = 2×10⁵ × 2.24 / 10⁹ = 4.48×10⁻⁴ 秒**

### 1.3 FLOPS单位换算
```
MFLOPS(10⁶) → GFLOPS(10⁹) → TFLOPS(10¹²) → PFLOPS(10¹⁵) → EFLOPS(10¹⁸)
```

### 1.4 基准测试程序
| 类别 | 程序 |
|------|------|
| 定点运算 | SPEC, Dhrystone |
| 浮点运算 | LinPack, Whetstone |
| 数据库 | TPC |
| 并行运算 | NPB |

### 1.5 性能影响因素
算法 → 编程语言 → 编译器 → 指令集体系结构 (ISA)，每个环节影响CPI、指令数和CPU时间。

## M02 数制与编码

### 2.1 进制转换（★必会）

#### 任意进制→十进制（位权展开）
**N = Σ(Dᵢ × rⁱ)**

#### 二进制↔八进制/十六进制
- 二→八：从小数点向左右每**3位**一组
- 二→十六：每**4位**一组
- 不足补零！

#### 十进制→二进制
- 整数：**除2取余**（低位→高位）
- 小数：**乘2取整**（高位→低位）

#### 简便运算
- 2¹⁰ = 1024 ≈ 10³ (K)
- 2²⁰ ≈ 10⁶ (M)
- 2³⁰ ≈ 10⁹ (G)
- 例：13/128 = 13/2⁷ = (1101)₂/2⁷ = 0.0001101B

### 2.2 四种机器码（★★必考重点）

| 码制 | 正数形式 | 负数形式 | 应用场景 |
|------|----------|----------|----------|
| **原码** | 符号0+数值 | 符号1+数值 | 浮点数尾数 |
| **反码** | 同原码 | 数值位按位取反 | 已淘汰 |
| **补码** | 同原码 | 反码+1（取反加1） | **整数标准** |
| **移码** | 补码符号取反 | 补码符号取反 | 浮点数阶码 |

#### 补码核心优势
1. **零的表示唯一**（无正零负零之分）
2. **符号位可直接参与运算**
3. **减法变加法**：`[X-Y]补 = [X]补 + [-Y]补`

#### 补码定义公式
- 整数：`[X]补 = X (0≤X<2ⁿ)`；`[X]补 = 2ⁿ⁺¹+X (-2ⁿ≤X<0)`
- 小数：`[X]补 = X (0≤X<1)`；`[X]补 = 2+X (-1≤X<0)`

### 2.3 定点数与浮点数

**定点数：** 小数点位置固定
- 定点整数（纯整数）：小数点在最低位后，范围 0≤|X|≤2ⁿ⁻¹
- 定点小数（纯小数）：小数点在符号位后，范围 0≤|X|≤1-2⁻ⁿ

**浮点数：** N = 2ᴱ × M（E=阶码, M=尾数）
- 表示范围远大于定点数
- 规格化：尾数绝对值最高有效位为1

### 2.4 IEEE754 单精度浮点数（★必考）

```
[S:1位] [E:8位(移码)] [M:23位(尾数,隐藏最高位1)]
x = (-1)ˢ × (1.M) × 2^(E-127)
```
- 阶码偏移量 = 127 (01111111B)
- 实际指数 e = E - 127

**例题：** (41360000)₁₆ → 展开 → S=0, E=130, e=3, 1.M=1.011011 → x = 1.011011×2³ = **11.375**

### 2.5 汉字编码

三种编码关系：
```
区位码 + 0x2020 = 国标交换码
区位码 + 0xA0A0 = 机内码
```
- GB2312：16位编码，7445个字符（6763个汉字+682个图形字符）
- 机内码每字节最高位置1，与ASCII严格区分

### 2.6 数据校验

| 方法 | 原理 | 能力 |
|------|------|------|
| 奇偶校验 | 使1的个数为奇/偶数 | 检奇数个错，不能纠错 |
| 海明校验 | 多校验位交叉校验 | 检错+纠错 |
| CRC | 多项式除法 | 检测突发错误 |

## M03 布尔代数基础

### 3.1 基本定律（★必背）

| 名称 | 公式 |
|------|------|
| 0-1律 | A+0=A, A·1=A, A+1=1, A·0=0 |
| 等幂律 | A+A=A, A·A=A |
| 互补律 | A+A'=1, A·A'=0 |
| 交换律 | A+B=B+A, A·B=B·A |
| 结合律 | (A+B)+C=A+(B+C), (AB)C=A(BC) |
| 分配律 | A(B+C)=AB+AC, A+BC=(A+B)(A+C) |
| 吸收律 | A+AB=A, A(A+B)=A, **A+A'B=A+B** |
| 德摩根律 | **(A+B)'=A'·B'**, **(AB)'=A'+B'** |
| 双重否定 | (A')'=A |

### 3.2 常用公式

| 编号 | 公式 | 名称 |
|------|------|------|
| 21 | A+AB = A | 吸收 |
| 22 | A+A'B = A+B | 冗余项消除 |
| 24 | AB+AB' = A | 合并 |
| **25** | **AB+A'C+BC = AB+A'C** | **冗余定理（考点）** |

### 3.3 三大规则

1. **代入规则**：等式中的变量可用任意表达式替换
2. **反演规则**：求函数Y的反函数 — `+↔·, 0↔1, 原变量↔反变量`，保持运算顺序
3. **对偶规则**：`+↔·, 0↔1`，若两式相等则其对偶式也相等

### 3.4 卡诺图化简（★★必考）

**步骤：**
1. 画出n变量的卡诺图（2ⁿ格）
2. 在真值表中为1的最小项对应格填1
3. **画卡诺圈**：圈住相邻的1（大小必须为2的幂：1,2,4,8...）
4. 圈越大越简（2格消1变量，4格消2变量，8格消3变量）
5. 每格至少被圈一次，圈内至少有一格未被其他圈覆盖
6. 每个圈写出对应的与项（不变变量保留，变化变量消去）
7. 所有与项相或即为最简与或式

**注意首尾相邻（卷绕相邻）！**

## M06 运算方法与运算器

### 6.1 补码加减运算

```
[X+Y]补 = [X]补 + [Y]补
[X-Y]补 = [X]补 + [-Y]补
```
其中 `[-Y]补 = [Y]补 按位取反 + 1`

### 6.2 溢出判断（★必考）

**单符号位法：** V = C_f ⊕ C₀（最高进位⊕次高进位）
- C_f: 符号位进位，C₀: 数值最高位向符号位的进位

**双符号位法（变形补码）：**
- 正数：00.xxx，负数：11.xxx
- 结果符号位为 01 → 正溢出；10 → 负溢出

### 6.3 全加器 (FA)

| 输入 | 输出 |
|------|------|
| Aᵢ, Bᵢ, Cᵢ | Sᵢ, Cᵢ₊₁ |

- Sᵢ = Aᵢ ⊕ Bᵢ ⊕ Cᵢ
- Cᵢ₊₁ = AᵢBᵢ + (Aᵢ⊕Bᵢ)Cᵢ

### 6.4 先行进位 (CLA) — 重要设计题

**进位生成/传递函数：**
- Gᵢ = Aᵢ·Bᵢ（绝对进位）
- Pᵢ = Aᵢ⊕Bᵢ（条件进位）

**并行进位公式：**
- C₁ = G₁ + P₁C₀
- C₂ = G₂ + P₂G₁ + P₂P₁C₀
- C₃ = G₃ + P₃G₂ + P₃P₂G₁ + P₃P₂P₁C₀
- C₄ = G₄ + P₄G₃ + P₄P₃G₂ + P₄P₃P₂G₁ + P₄P₃P₂P₁C₀

**组间进位：** G* = G₄+P₄G₃+P₄P₃G₂+P₄P₃P₂G₁；P* = P₁P₂P₃P₄

### 6.5 原码一位乘法

**步骤：**
1. 部分积初始为0
2. 看乘数最低位：为1则加被乘数；为0则加0
3. 部分积与乘数联合右移一位
4. 重复n次
5. 符号位 = 两数符号异或

### 6.6 Booth算法（补码一位乘法）

**规则（看YᵢYᵢ₊₁）：**
- 01: 部分积 + [X]补
- 10: 部分积 + [-X]补
- 00/11: 部分积 + 0
- 算术右移一位，重复n+1次

### 6.7 原码除法（恢复余数法）

1. 被除数减去除数
2. 余数≥0 → 商上1；余数<0 → 商上0，恢复余数
3. 左移，继续减
4. 符号位 = 两数符号异或

### 6.8 浮点数加减运算（五步法 ★★）

1. **对阶**：小阶向大阶对齐，阶差决定右移位数
2. **尾数求和**：补码加减
3. **规格化**：左规（左移减阶）或右规（右移加阶）
4. **舍入**：0舍1入 或 末位恒置1
5. **溢出判断**：阶码是否溢出

### 6.9 ALU (SN74181)

- 4位ALU芯片，M=0算术运算，M=1逻辑运算
- S₀-S₃选择具体操作（16种算术+16种逻辑）
- 级联：4片74181 + 1片74182 = 16位带先行进位的ALU

## M07 存储系统

### 7.1 存储系统层次结构（★必考）

```
寄存器(CPU内) → Cache(SRAM) → 主存(DRAM) → 辅存(磁盘)
   速度递减，容量递增，价格递减
```

### 7.2 存储器分类

| 分类方式 | 类型 |
|----------|------|
| 存储介质 | 半导体/磁/光 |
| 存取方式 | RAM/SAM |
| 读写能力 | ROM/RAM |
| 易失性 | 易失(SRAM,DRAM) / 非易失(磁盘,CD-ROM) |

### 7.3 SRAM vs DRAM（对比重点）

| 特性 | SRAM | DRAM |
|------|------|------|
| 存储元件 | 触发器(6管) | 电容+MOS管(1管) |
| 速度 | 快 | 较慢 |
| 集成度 | 低 | 高 |
| 功耗 | 大 | 小 |
| 刷新 | 不需要 | **需要刷新** |
| 用途 | Cache | 主存 |

### 7.4 DRAM刷新（★★计算考点）

**三种刷新方式：**
| 方式 | 特点 | 死时间 |
|------|------|--------|
| 集中刷新 | 所有行连续刷新 | 有 |
| 分散刷新 | 每个存取周期刷新一行 | 无 |
| 异步刷新 | 每隔 t/n 刷新一行 | 极短/无 |

刷新周期通常为 **2ms**，按行刷新。

**例题**：128行×128列，R/W周期50ns，刷新周期2ms
- 集中刷新死时间 = 128×50ns = 6400ns

### 7.5 存储器扩展（★设计题）

| 扩展类型 | 方法 | 芯片数 |
|----------|------|--------|
| 位扩展 | 地址线和控制线共用，数据线分开 | d = 总容量/芯片容量 |
| 字扩展 | 数据线共用，高位地址译码选片 | 同上 |
| 字位同时扩展 | 先位扩展成组，再字扩展 | d = (总字/片字)×(总位/片位) |

### 7.6 多体交叉存储器（★★）

- **高位交叉（顺序）**：高位地址选模块，串行工作
- **低位交叉**：低位地址选模块，流水线并行

**流水线访问时间**：t = T + (n-1)×τ
- T = 模块存取周期, τ = 总线传送周期
- 交叉度 m = T/τ

### 7.7 Cache（★★★重难点）

#### 地址映射三种方式

| 映射方式 | 主存地址格式 | 特点 |
|----------|-------------|------|
| **全相联** | \| 标记(块号) \| 块内偏移 \| | 任意块→任意行，灵活但比较器多 |
| **直接相联** | \| 标记(区号) \| 行索引 \| 块内偏移 \| | 固定映射，简单但冲突多 |
| **组相联** | \| 标记 \| 组索引 \| 块内偏移 \| | 折中方案，每组k路 |

#### 替换算法
| 算法 | 原则 |
|------|------|
| FIFO | 替换最早装入的块 |
| LRU | 替换最久未使用的块 |
| LFU | 替换使用次数最少的块 |
| 随机 | 随机选择 |

#### 写策略
| 策略 | 做法 |
|------|------|
| 写回法 | 只写Cache，替换时写回主存（需要脏位） |
| 全写法 | 同时写Cache和主存 |

#### 性能公式（★必考）
- **命中率**：H = Nc / (Nc+Nm)
- **平均访问时间**：**ta = H×tc + (1-H)×tm**
- **访问效率**：e = tc/ta × 100%

### 7.8 虚拟存储器

#### 页式管理
- 虚地址 = VPN(虚拟页号) + VPO(页内偏移)
- 物理地址 = PPN(物理页号) + PPO
- 页表：VPN→PPN的映射表

#### TLB（快表/★考点）
- TLB是页表的Cache，存放最近使用的页表项
- 用相联存储器实现，快速虚实地址转换
- TLB命中 → 直接获得PPN；TLB缺失 → 访问主存中的慢表

#### 段式管理
- 按程序逻辑分段（如函数），段长可变
- 段表项：有效位 + 段基址 + 段长

## M08 指令系统

### 8.1 指令格式

```
[操作码 OP] [地址码 A]
```
- 操作码：指明做什么操作
- 地址码：指明操作数在哪里

### 8.2 寻址方式（★★必考重点）

| 寻址方式 | EA公式 | 特点 |
|----------|--------|------|
| 立即寻址 | 操作数=指令中立即数 | 最快，灵活性差 |
| 直接寻址 | EA=A | 简单，寻址范围受限 |
| 间接寻址 | EA=(A) | 灵活，多次访存 |
| 寄存器直接 | EA=R | 快，寄存器少 |
| 寄存器间接 | EA=(R) | 灵活 |
| 变址寻址 | EA=(R)+A | 适合数组访问 |
| 基址寻址 | EA=(B)+A | 支持程序重定位 |
| 相对寻址 | EA=(PC)+A | 用于转移指令 |
| 堆栈寻址 | EA=(SP) | 隐含操作数 |

### 8.3 扩展操作码

通过操作码位数可变来支持不同地址数量的指令。例如指令字长16位：
- 三地址：(4位OP, 3×4位地址)
- 二地址：(8位OP, 2×4位地址)
- 一地址：(12位OP, 1×4位地址)
- 零地址：(16位OP)

### 8.4 MIPS指令格式

| 类型 | 格式 | 用途 |
|------|------|------|
| R型 | OP(6)\|RS(5)\|RT(5)\|RD(5)\|shamt(5)\|funct(6) | 寄存器运算 |
| I型 | OP(6)\|RS(5)\|RT(5)\|Immediate(16) | 立即数/访存/分支 |
| J型 | OP(6)\|Target(26) | 跳转 |

### 8.5 CISC vs RISC（★简答题高频）

| 特性 | CISC | RISC |
|------|------|------|
| 指令数量 | 多(200+) | 少(<100) |
| 指令长度 | 可变 | 固定 |
| 寻址方式 | 多 | 少 |
| 控制器 | 微程序 | 硬布线 |
| 代表 | x86 | MIPS, ARM |
| 设计哲学 | 硬件完成复杂功能 | 软件+简单硬件 |

## M09 中央处理器

### 9.1 CPU组成

**CPU = 运算器 + Cache + 控制器**

| 部件 | 主要寄存器 |
|------|-----------|
| 运算器 | ALU, GR(通用寄存器组), DR, PSW |
| 控制器 | PC, IR, AR/MAR, DR/MDR, 时序发生器, 指令译码器 |

### 9.2 CPU五大功能
1. 数据加工（ALU）
2. 程序控制（指令执行顺序）
3. 操作控制（指令→控制信号）
4. 时序控制（信号时序）
5. 异常控制（中断/异常处理）

### 9.3 数据通路

| 总线结构 | 暂存器 | ADD周期 | 性能 |
|----------|--------|---------|------|
| 单总线 | 2个 | 3周期 | 最低 |
| 双总线 | 1个 | 2周期 | 中等 |
| 三总线 | 0个 | 1周期 | 最高 |

### 9.4 三级时序系统

```
指令周期 > 机器周期(CPU周期) > 时钟周期(节拍)
```
- 一个指令周期包含若干机器周期
- 一个机器周期包含若干时钟周期
- 一个时钟周期完成一个微操作

### 9.5 控制器设计（★★）

#### 硬布线控制器 vs 微程序控制器

| 特性 | 硬布线 | 微程序 |
|------|--------|--------|
| 实现方式 | 组合逻辑电路 | 控存(ROM)存微指令 |
| 速度 | **快** | 慢（频繁访问控存） |
| 灵活性 | 差，难修改 | **好，易扩展** |
| 复杂性 | 不规则 | 规整 |
| 适用 | **RISC** | **CISC** |
| 成本 | 高 | 低 |

#### 硬布线控制信号公式
```
C = f(指令译码I, 机器周期M, 节拍T, 反馈B)
```
例：`Read = MIF·(T2+T3) + LOAD·MEX·(T2+T3)`

#### 微程序相关概念
- **微指令**：操作控制字段 + 顺序控制字段（判别字段P + 下址字段）
- **微程序**：一段微指令序列对应一条机器指令
- **控存**：存放所有微程序的ROM

#### 水平型 vs 垂直型微指令
| 特性 | 水平型 | 垂直型 |
|------|--------|--------|
| 字长 | 长 | 短 |
| 并行性 | 高 | 低 |
| 速度 | 快 | 慢 |
| 微程序长度 | 短 | 长 |

### 9.6 MIPS单周期CPU

- CPI = 1（所有指令一个周期完成）
- 哈佛结构：指令存储器和数据存储器分开
- 控制器为纯组合逻辑
- 不能使用AR、DR、IR寄存器

**8条核心指令**：add, slt, addi, lw, sw, beq, bne, syscall

### 9.7 指令执行RTL示例

取指周期（公操作）：
```
T1: PC→AR, PC→X
T2: (X)+1→Z, Read
T3: Z→PC, Mem[AR]→DR
T4: DR→IR
```
